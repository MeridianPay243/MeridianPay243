How 403 Errors Are Prevented

1. Per-Customer Key Isolation: Netlify creates a Checkbook Marketplace user (POST /v3/user) with our Owner key, then signs /bank, /release, /verify, and /invoice/payment with that customer’s returned key:secret.
2. Built-In Checkbook IAV + Micro-Deposits: Both instant bank login (/v3/account/bank/iav) and manual routing/account (/v3/account/bank) run through Checkbook’s API with zero external SDK keys required.
3. Programmatic Auto-Debit: Invoices target the internal user_id slug so Netlify can auto-debit immediately upon invoice creation.
